# ZKP-DID Framework — ZK Circuit Guide

## Circuit Overview

All circuits use the **Groth16** proving scheme on the **BN128** (BN254) curve.

### Shared Conventions

- All field elements are in the BN128 scalar field (prime ~2²⁵⁴)
- Poseidon hash is used everywhere (ZK-friendly, ~50 constraints per call)
- EdDSA signatures use the Baby Jubjub curve
- `commitment = Poseidon(secret_value, nonce)` — hides private inputs
- `nullifier = Poseidon(credHash, nonce)` — session-unique, unlinkable

## Circuit 1: `credential_proof` — Master Proof Circuit

```
Private Inputs:
  attributes[4]   — [age, orgId, trustScore, qualCode] (field elements)
  credHash        — Poseidon hash of the full credential
  sigR8[2]        — EdDSA signature R point (x, y)
  sigS            — EdDSA signature S scalar
  issuerPubKey[2] — Issuer's Baby Jubjub public key (x, y)
  nonce           — Session nonce from verifier challenge

Public Inputs (revealed to verifier):
  policyResult    — 1 if policy satisfied, 0 otherwise
  commitment      — Poseidon(attributes[0..3], nonce)
  nullifier       — Poseidon(credHash, nonce)

What is proved:
  1. commitment == Poseidon(attributes, nonce)             [binding]
  2. EdDSA.verify(issuerPubKey, credHash, sigR8, sigS)    [authenticity]
  3. nullifier == Poseidon(credHash, nonce)                [linkability prevention]
  4. policyResult === 1                                    [policy compliance]
```

## Circuit 2: `age_threshold` — Age Predicate

```
Private Inputs:
  birthYear   — e.g., 1990
  nonce       — session nonce

Public Inputs:
  currentYear — e.g., 2025
  threshold   — e.g., 18
  commitment  — Poseidon(birthYear, nonce)

Constraints:
  age = currentYear - birthYear
  age >= threshold  (GreaterEqThan gadget)
  commitment == Poseidon(birthYear, nonce)
```

## Circuit 3: `org_membership` — Merkle Inclusion

```
Private Inputs:
  orgId           — organisation identifier
  nonce           — session nonce
  pathElements[10] — Merkle sibling hashes
  pathIndices[10]  — left/right indicators

Public Inputs:
  merkleRoot  — approved orgs Merkle tree root
  commitment  — Poseidon(orgId, nonce)

Constraints:
  MerkleTreeChecker(orgId, pathElements, pathIndices) == merkleRoot
  commitment == Poseidon(orgId, nonce)
```

---

## Circuit 4: `trust_score` — Score Threshold

```
Private Inputs:
  trustScore  — integer 0-100 (or 0-1000 for precision)
  nonce       — session nonce

Public Inputs:
  threshold   — required minimum score
  commitment  — Poseidon(trustScore, nonce)

Constraints:
  trustScore >= threshold  (GreaterEqThan gadget)
  commitment == Poseidon(trustScore, nonce)
```

## Compiling Circuits

```bash
# Prerequisites
npm install -g snarkjs
# Install circom (Rust): https://docs.circom.io/getting-started/installation/

# Compile circuit
circom circuits/age_threshold.circom --r1cs --wasm --sym -o zkp-service/circuits/

# Powers of Tau (reuse public ceremony up to 2^15 constraints)
snarkjs powersoftau new bn128 15 pot15_0.ptau -v
snarkjs powersoftau contribute pot15_0.ptau pot15_1.ptau --name="First contribution" -v
snarkjs powersoftau prepare phase2 pot15_1.ptau pot15_final.ptau -v

# Generate proving key (zkey)
snarkjs groth16 setup circuits/age_threshold.r1cs pot15_final.ptau zkp-service/zkeys/age_threshold_0.zkey
snarkjs zkey contribute zkp-service/zkeys/age_threshold_0.zkey zkp-service/zkeys/age_threshold_final.zkey

# Export verification key
snarkjs zkey export verificationkey zkp-service/zkeys/age_threshold_final.zkey zkp-service/zkeys/age_threshold_vkey.json

# Export Solidity verifier
snarkjs zkey export solidityverifier zkp-service/zkeys/age_threshold_final.zkey hardhat/contracts/Verifier.sol
```

## Proof Generation (JavaScript/TypeScript)

```typescript
import { groth16 } from 'snarkjs';

// Generate proof
const { proof, publicSignals } = await groth16.fullProve(
  {
    birthYear: 1990n,
    nonce: BigInt('0x' + crypto.randomUUID().replace(/-/g, '')),
  },
  'zkp-service/circuits/age_threshold_js/age_threshold.wasm',
  'zkp-service/zkeys/age_threshold_final.zkey'
);

// Verify proof
const vkey = JSON.parse(fs.readFileSync('zkp-service/zkeys/age_threshold_vkey.json'));
const isValid = await groth16.verify(vkey, publicSignals, proof);
console.log('Valid:', isValid); // true
```

## Security Properties

| Property | Mechanism |
|----------|-----------|
| Completeness | Valid witness always produces accepted proof |
| Soundness | Groth16 knowledge soundness (under knowledge of exponent assumption) |
| Zero-knowledge | Simulator exists for any valid public input tuple |
| Binding | Poseidon commitment is collision-resistant |
| Non-replayability | Nullifier tracks per-session proof use |
| Issuer authenticity | EdDSA signature verified in-circuit |
| Revocation | On-chain nullifier/credential hash check |
